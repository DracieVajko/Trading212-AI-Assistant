# Research notes: external briefs

This folder stores **dated summaries** of external market briefings. The
general rules distilled from them live in
`../market-evaluation-playbook.md`; this folder keeps the evidence trail.

## Rules

- One file per brief: `YYYY-MM-DD-<source>.md`.
- Summarise facts, not opinions dressed as facts.
- Keep day-specific calls here; never hardcode them into trading logic.
- Record what confirmed/invalidated at the next review.
- Do not copy personal data, account values or credentials.
